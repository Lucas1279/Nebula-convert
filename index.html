Pick the file to write. It is streamed while converting, so it never has to fit in memory. You can point it straight at your (exFAT) USB stick. An existing file with the same name will be overwritten.

    🔭 How it works, compatibility & troubleshooting
    

      
What exactly happens to my file? In Turbo remux the video (and any compatible audio)
        is copied bit-for-bit from the MKV into an MP4 container — identical picture and sound, zero re-encoding.
        Only streams the PS5 can’t play (DTS, TrueHD, FLAC, Opus audio…) get re-encoded to AAC-LC.
        Because everything is streamed, RAM use stays flat (~200 MB) whether the file is 700 MB or 70 GB.

      
Why won’t some MP4s play on the PS5? Sony’s media player officially accepts MP4 with
        H.264 High Profile (≤ Level 5.2) video and AAC-LC audio, plus WebM (VP9/Opus).
        Files that fail are usually: H.265/HEVC video (plays on most PS5s per community testing, but isn’t on Sony’s list),
        DTS/AC-3/TrueHD audio, 10-bit H.264, or anything on a FAT32 stick over 4 GB.
        The PS5-proof mode removes all doubt by rebuilding video as H.264 High + AAC.

      
Is it really under a minute? A copy conversion moves roughly 2× the file size (read + write).
        On an NVMe SSD (~500 MB/s+) a 20 GB movie finishes in about a minute; on a slower disk or a USB stick
        it takes proportionally longer — the limit is your hardware, not this page. Re-encoding modes depend on your
        GPU/CPU and typically run several times faster than playback.

      
Subtitles? The PS5’s Media Gallery ignores embedded subtitles entirely, and MKV subtitle
        formats (PGS, ASS/SSA) can’t live in an MP4 — subtitle tracks are dropped and listed in the log. Burn them in
        beforehand if you truly need them on the TV.

      
HDR / 10-bit? Turbo remux keeps HEVC HDR10 exactly as-is (the PS5 plays it, QuickTime on a
        modern Mac too). If you force H.264 via PS5-proof or Compress, HDR is converted to plain
        SDR and colours can look washed out — for HDR movies prefer keeping HEVC.

      
Which containers can I feed it? MKV, WebM, MP4, MOV/M4V, MPEG-TS / M2TS (AVCHD, including
        from camcorders), OGG, raw AAC/ADTS, MP3, FLAC, WAV. AVI, WMV, FLV and DVD VOBs aren’t supported in-browser —
        the page tells you immediately if you drop one.

      
Browser notes: Chrome/Edge give the best experience (streaming “Save to a file”, full
        hardware re-encode). Safari and Firefox work via the download path and support most re-encodes, but can’t
        stream multi-GB outputs to a chosen file. Everything is powered by WebCodecs + the
        mediabunny engine.

      
PS4? PS5-proof output (H.264 ≤ 1080p… actually ≤ L4.2 for PS4) also plays on a PS4 from the
        same exFAT/FAT32 stick. HEVC does not play on PS4.

      
Privacy: this page has no server component and makes no network requests at conversion time.
        Use “Save page” and it even works offline. The only data written is the output you choose.
